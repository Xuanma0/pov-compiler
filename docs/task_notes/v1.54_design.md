## residual_risks

- `core_real_v2_candidate` reduced weak-query groups, but it did not improve strict retrieval on the aligned medium-scale run, so promotion remains blocked.
- The aligned compare is clean, but the evidence is still not strong enough to justify overwriting `core_real_v1`; `v2` should stay appendix/candidate-only for now.
- The next decision boundary is no longer provider reachability. It is whether to expand sample size first or revisit segmentation support only after a larger aligned `v2` run still fails to move strict metrics.
