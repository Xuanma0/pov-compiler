## residual_risks

- Promotion and admission are now explicitly separated, but the current large-sample wording still needs a caveat because the sample contract is borderline rather than fully hardened.
- The remaining non-hardened evidence is primarily sample/coverage strength plus a provider-availability semantics gap in the existing admission output, not a failure of the persistent-memory compare itself.
- The paper/export layer is now explicit, but downstream readers still need to follow the fixed order `compare -> decision -> cleanup -> sample_contract` to avoid over-reading the mainline claim.
- `pytest -q -n auto` required hardening at the test harness layer: `tests/conftest.py` now caps `auto` workers to a stable upper bound, and `src/pov_compiler/bench/reporting/__init__.py` now lazy-loads heavy reporting helpers so cleanup/sample-contract scripts do not drag `pandas/matplotlib` into every import path.
