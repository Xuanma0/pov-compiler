## residual_risks

- Persistent object memory v2 clearly improves reappearance, lost-object, chain grounding, and query-strength coverage, but total object-memory item count still does not increase, so memory usefulness improved more than raw memory volume.
- The baseline still points at downstream consumption (`need_decision_side_fix`), so a future failure mode is that better persistent memory exists but is still not consumed aggressively enough by later retrieval or decision layers.
- This milestone is strong enough to justify promoting persistent object memory logic, but not yet enough to prove that larger main-real gains will follow without a medium-scale follow-up.
