## Single Goal

- Promote the benchmark suite from a freeze/archive layer into a real main-result execution layer with one canonical runner, health gate enforcement, canonical paper numbering, paper-level freeze, and non-demo paper/export packaging.

## Boundary

- Keep all logic on collect / aggregate / export / provenance layers.
- Do not rewrite evaluator logic.
- Do not duplicate compare logic in the new runner.
- Do not touch runtime core orchestrators.
