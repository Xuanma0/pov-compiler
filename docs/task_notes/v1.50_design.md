# v1.50 Design + Implementation Note

## Single goal

- Move the real-pilot result layer from “provider unavailable but fully diagnosed” to “live-call proof + reusable golden real sample”, while keeping all changes on collect / aggregate / export / provenance layers.

## Scope boundary

- Keep work on result-layer scripts, reporting sidecars, and export/pack flow.
- Reuse the existing `openai_compat` client; do not add a new provider client.
- Do not reimplement evaluator logic.
- Do not modify runtime core files such as `pipeline.py`, `retriever.py`, `streaming/runner.py`, `eval_nlq.py`, or compare producers.

## residual_risks

- The v1.50 “real” golden pilot uses a live OpenAI-compatible proof path plus stable fixture compare sources; it proves reachability and end-to-end export closure, but it is not yet a live compare-root ingestion path.
- `admission_status` and `calibration_status` remain conservative because the pilot still surfaces weak or zero-effect deltas even after reachability is fixed.
- `export_paper_ready.py` still emits harmless matplotlib legend warnings for panels with sparse inputs; outputs are complete, but the plotting path could be cleaned up in a follow-up.
