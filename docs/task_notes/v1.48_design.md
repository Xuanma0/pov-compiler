# v1.48 Design And Closure

## Single Goal

- Promote the v1.47 admission-controlled pilot flow into a calibration-aware and query-aware result layer, so a small `main_real` pilot can say whether the admission profile is sensible and whether weak deltas come from weak queries rather than weak algorithms.

## Boundary

- Keep all work on collect / aggregate / export / provenance layers.
- Do not rewrite evaluator logic.
- Do not duplicate compare logic.
- Do not modify runtime core orchestrators or schema contracts.

## gate_status

## admission_status

- fake small pilot admission status: `ok`
- `admission_control/` remains independent from calibration. It still answers whether the current pilot is acceptable, while calibration only suggests how to tune thresholds for the next pilot.

## calibration_status

- fake small pilot calibration status: `ok`
- calibration confidence: `high`
- recommended next profile on the fixture path keeps `min_selected_uids=2`, tightens `max_no_data_rate=0.05`, and keeps provider-noise tolerances low enough that future live pilots should still fail loudly when parse/fallback noise dominates.

## query_strength_summary

- fake small pilot main recommendation: `promote_to_core_query_bank`
- action counts: `{"keep_for_analysis_only": 1, "promote_to_core_query_bank": 2, "strengthen_signal_support": 1}`
- on the fixture path, `repo_summary` stays analysis-only because the fake compare root does not expose a main-result repo task, while the stronger `decision`/`chain` groups remain main-result candidates.

## residual_risks

- `v1.48` still validates on the fake compare root; a live real-root pilot can still degrade to `partial` or `weak` if selected UID coverage or paired significance is much weaker than the fixture path.
- query-strength audit currently works at frozen query-group granularity rather than true per-query execution traces. That is enough for pilot triage, but a future live pilot may still need deeper attribution before pruning a query bank.
- `export_paper_ready.py` still emits harmless Matplotlib legend warnings on sparse panels. Artifacts are written correctly, but the plotting code still assumes optional lines may be absent.
