## residual_risks

- `YOLO26n` now improves the signal layer enough to flip `signal_uplift_status=improved`, but the real pilot still ends with `query_bank_still_too_weak`, so the bottleneck is no longer only provider availability.
- The runtime change stayed minimal, but cache correctness now depends on `model_path` and `hand_task_model_path`; future local-model work should preserve that contract to avoid false uplift wins from stale cache.
- `SAM3` should remain the next segmentation candidate only if the current uplift report keeps showing stronger object coverage but insufficient lost-object/query-strength gains.
- `DA3` remains out of scope for this round and should stay on the later geometry track instead of getting mixed into the current signal-uplift conclusion.
