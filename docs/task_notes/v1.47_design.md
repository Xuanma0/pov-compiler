# v1.47 Design And Closure

## Single Goal

- Promote the telemetry-aware pilot flow into an admission-controlled real-pilot result layer, so small `main_real` pilots can explicitly say whether they are worth expanding and which layer should be tuned next.

## Boundary

- Keep all work on collect / aggregate / export / provenance layers.
- Do not rewrite evaluator logic.
- Do not duplicate compare logic.
- Do not modify runtime core orchestrators or schema contracts.

## residual_risks

- `v1.47` still validates on the fake compare root; a live real-root pilot can still degrade to `partial` if UID coverage, paired significance, or provider availability is weaker than the fixture path.
- `export_paper_ready.py` continues to emit harmless Matplotlib legend warnings on sparse inputs; artifacts are written correctly, but the plotting code still assumes optional panels may be present.
- The current delta-audit heuristics are intentionally lightweight. They are sufficient for admission triage, but a future live pilot may need richer mapping from weak deltas to query-bank/perception/repo/planner causes.
