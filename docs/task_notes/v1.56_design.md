# v1.56 Object-Memory Logic Uplift

## Goal

- Keep the `YOLO26n + SAM3` perception path fixed and test the smallest possible `object_memory_v0` uplift.
- Verify whether persistence-backed memory improves lost-object support, chain object grounding, and query strength enough to justify moving this logic into the main line.
- Preserve the existing output contract and keep retrieval, streaming, and evaluator logic untouched.

## residual_risks

- The uplift clearly increases persistence-backed memory items and chain grounding, but it still does not increase total memory items, so the next bottleneck is memory usefulness rather than raw persistence volume.
- `lost_object_query_support_rate` stayed flat on the real run even after the memory uplift, so the current change is not yet strong enough to justify a larger main-real rollout.
- Because the persistence path now looks healthier than the query outcome, the next failure mode is likely downstream consumption in retrieval or decision logic rather than missing segmentation signal.
