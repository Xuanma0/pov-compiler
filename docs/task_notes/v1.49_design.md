- Move the pilot stack from fake-only confidence building to a real small-pilot contract that can normalize provider telemetry and export a provenance-safe query promotion pack without modifying runtime core modules.

## Scope boundary

- Keep work on collect / aggregate / export / provenance layers.
- Do not reimplement evaluator logic.
- Do not copy compare logic into the pilot runner.
- Do not modify runtime core files such as `pipeline.py`, `retriever.py`, `streaming/runner.py`, `eval_nlq.py`, or `run_ab_bye_compare.py`.
