# v1.43 Design And Closure

## Single Goal

- Converge the v1.42 benchmark suite into a real main-result production line with frozen query banks, fixed real/fake manifests, explicit result-health reporting, benchmark artifact freeze, and paper-ready/submission-pack integration.

## Boundary

- Keep the implementation on the collect / aggregate / export / provenance layer.
- Do not rewrite evaluator logic.
- Do not copy compare logic into the suite runner.
- Do not touch oversized runtime orchestrators.
- Forbidden runtime files were not modified in this implementation.

## residual_risks

- `main_real` is frozen, but real main-result quality still depends on upstream compare roots having enough signal-rich data.
- Sparse compare inputs can still make paper-ready plotting emit legend warnings, even though the export succeeds.
- Query-bank freeze protects input provenance, but does not by itself guarantee that upstream source compare directories were generated from the same code revision.
