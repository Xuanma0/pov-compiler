## residual_risks

- The candidate bank is still derived from small-pilot evidence, so it should remain a `candidate` and not replace `core_real_v1` silently.
- `repo_summary` remains analysis-only; the current evidence does not justify putting it back into the main bank.
- `YOLO26n` improved signal consumption enough for `decision / chain / lost_object`, but the result still needs a larger real sample before promoting the bank to the formal main-result contract.
