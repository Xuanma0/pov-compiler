## residual_risks

- `promotion_ready` is now stable under the harder paired contract, but `mainline_admission_ready` is still blocked by provider availability semantics rather than sample/coverage weakness.
- `large_sample_claim_status` is now `supported`, but the final admission closure remains `partial_but_harder`; paper wording should avoid implying fully clean admission until provider semantics are cleaned up.
- The hardening work stayed entirely in benchmark/report/export/provenance space; if future closure still stalls after provider semantics cleanup, the next step should be wording/contract refinement, not runtime expansion.
