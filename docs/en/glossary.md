# Glossary

- Purpose: Keep core project terms stable across English and Chinese docs.
- Version scope: `v1.60+`
- Reading order: current mainline status -> this document as needed.
- Related docs: [current_mainline_status.md](./current_mainline_status.md), [development_workflow.md](./development_workflow.md)

| Term | Chinese | Meaning |
|---|---|---|
| persistent memory | 持久记忆 | The promoted persistent object-memory route used in the current mainline. |
| mainline admission | 主线准入 | Whether the evidence is clean and complete enough to claim the route as the current mainline. |
| sample contract | 样本契约 | Frozen paired-sample evidence: UID set, budget, query bank, provider/perception alignment. |
| coverage contract | 覆盖率契约 | Coverage thresholds used to justify sample hardness and wording. |
| provider semantics gap | provider 语义缺口 | Residual ambiguity from provider-side availability semantics that does not invalidate promotion but still affects admission cleanliness. |
| paper_ready | 论文导出版 | The unified report/tables/figures export used for paper drafting. |
| submission_pack | 投稿归档包 | The self-contained evidence pack used for review or handoff. |
| promotion | 提升/晋升结论 | Relative comparison result saying a route should replace the baseline. |
| admission | 准入结论 | Evidence completeness result for whether the route is clean enough as the mainline. |
| partial_but_harder | 更硬但仍未完全闭合 | A state where evidence is stronger than before, but not fully clean enough. |
